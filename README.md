# Mobile First

## Resumen

Landing de práctica para un servicio de información sobre criptomonedas. Está diseñada desde móvil y reúne una tabla de tasas, características y planes.

## Cómo verlo

Abre [index.html](index.html) y amplía la ventana para ver el cambio de distribución.

[css/styles.css](css/styles.css) reúne los estilos base. [css/table.css](css/table.css) adapta la composición en pantallas más amplias.

## English summary

A mobile-first landing page exercise for a cryptocurrency information service. It presents exchange rates, features, and plans.
